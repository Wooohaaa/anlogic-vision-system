# 比赛提交工程说明

作品为基于安路 PH1P35 的实时图像处理与视觉交互系统，最终固件版本为 R6 areaopt4 FPGA 与 MCU r18。

## 提交内容

- `contest2_hdmi_video/`：FPGA RTL、安路 IP、ROM 初始化数据、TD 工程、引脚与时序约束、仿真及工程工具。
- `mcu_tracking/`：ArUco、双轴步进控制和 MCU 应用源码。
- `vendor/anlogic_sdk/`：MCU 编译依赖及原始许可声明。
- `firmware/`：FPGA、MCU、启动程序和联合 SPI Flash 镜像。
- `verification/`：最终资源及时序报告、R6/r18 源码快照、构建记录和镜像校验信息。
- `docs/`：正式比赛技术文档及操作说明。
- `PACKAGE_MANIFEST.json`：包内文件的 SHA256 清单。

## 源码版本

仓库保留维护源码及独立发布快照。执行以下命令可生成已应用 R6/r18 源码的完整提交目录：

```powershell
python tools/prepare_submission.py --output C:/Anlogic/submission/PH1P35_R6_r18
```

生成的目录已将最终构建使用的三份 FPGA 差异源码与 MCU r18 源码写入默认工程位置，并同步 TD 工程副本。准备过程核对 FPGA RTL、22 份 MCU 源文件与交付固件哈希；布局布线 seed 为 2，Slice 上限为 20,091，MCU 使用 `-Os`，载荷版本为 95。准备及打包过程不访问开发板。

RAR 压缩包内的工程已完成上述准备步骤，解压后直接使用根目录入口即可。原始发布固件及其 Routed 报告保存在 `firmware/`、`verification/r6_reports/`，重新构建的报告和镜像由工具另行输出。

## 构建与下载

安装 Windows 版安路 TD 工程师版、FutureDynasty 和 Python 3.11 或更新版本。复制 `config.example.json` 为 `config.local.json`，设置 TD、FD 目录及不含空格的 MCU 编译暂存路径。

```powershell
python -m pip install -r requirements.txt
python tools/repository.py verify
python tools/repository.py mcu
python tools/repository.py fpga
python tools/repository.py flash-image
```

`verify` 只检查文件完整性与工程一致性。`mcu`、`fpga` 和 `flash-image` 生成新的构建产物，均不烧录硬件。工具版本、布局布线条件及编译路径可能使重新生成文件的哈希发生变化，应以当次报告确认资源和时序。

使用交付的联合固件下载时，连接开发板和 AL-LINK-FT，启动 FutureDynasty 调试服务后执行：

```powershell
python tools/repository.py program
```

只有 `program` 访问开发板并写入 Flash；其余命令用于离线工程操作。板上操作及接口接线参见正式技术文档和 `docs/操作与部署.md`。
