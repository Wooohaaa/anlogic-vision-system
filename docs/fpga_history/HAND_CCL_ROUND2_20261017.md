# 手势原型第二轮：基准片段通过，扰动验证仍未通过

## 结论和边界

隔离软件原型 `ccl_shadow_v19` 已使两段原始视频的固定稳定标注段全部分类正确：旧片 288/288，新片 250/250。两段完整解码视频分别输出 870、818 帧 CSV，没有只回放有利片段。标注文件沿用上一轮审计版本，本轮没有改标签。

**这不是整段视频 100% 准确，更不是泛化、RTL 等价或上板签收。** 两段视频均参与了开发调试，没有独立留出场景；运动过渡/不确定手型未标注。稳定标注共 538 帧，只覆盖 1688 个源帧的一部分。框位置尚无人工真值，分类通过不能替代整手分割或框精度验收。暗部拳头的部分框仍只包到较亮区域。

新增了固定模型的 14 项双视频基准/扰动回归，并独立复算 CSV 和校验原片、采样、标注及冻结模型 SHA256。签收为 **`BASELINE_ONLY_STRESS_NOT_QUALIFIED`**，没有提升为可替换 RTL 的版本。

## 本轮实现

1. 严格肤色种子＋8 次受限生长，低亮像素必须与种子相连，不能仅靠放宽全局阈值生成前景；不学习首帧背景。
2. 生长后若连到画面边缘或面积过大，退回原种子，避免手腕与背景并成大块。归一化色差约束用于减少亮灰背景误入。
3. 在距离变换的行峰中优先寻找上方掌部，而不是取下方粗前臂作为掌心。
4. 拳头/单指歧义时增加凸起横截面宽度、相对腕部方向及短侧向拇指排除。对三个及以上指尖保留张手判定。
5. 补充凸包会漏掉的共线中间指尖：只在两个近似等长外侧尖端之间，寻找足够远的凸轮廓转角；合成三个等高指尖测试通过，合成对称 V 仍保持不确定。
6. 保留 legacy 模式，用于原型对照；双视频回归脚本明确选择 hybrid/lobe 模式。

当前几何约束仍要求完整手型、掌部大致位于腕部上方；候选掌半径至少为 320×180 采样图的 10 像素，候选高度至少 32 像素。小手、裁切和大幅翻转没有通过本轮验证，不宣称旋转/尺度不变。

## 固定模型扰动结果

| 测试 | 旧片稳定帧正确数 | 新片稳定帧正确数 |
|---|---:|---:|
| 原始输入 | 288/288 | 250/250 |
| RGB 统一 ×0.90 | 288/288 | 233/250 |
| RGB 统一 ×1.10 | 288/288 | 237/250 |
| R ×1.05，B ×0.95 | 256/288 | 202/250 |
| R ×0.95，B ×1.05 | 287/288 | 235/250 |
| 每通道四像素和加均匀 ±4 噪声 | 288/288 | 245/250 |
| ×0.90 后叠加上述噪声 | 288/288 | 225/250 |

每项都用同一模型、同一标注和完整视频，不豁免失败片段。统一增益和独立均匀噪声只是四像素和域的敏感性试验，不是传感器噪声、自动曝光、光子统计、ISP 或真实低照度的完整物理模拟。偏色仍然是主要薄弱项，不能因为基准通过就开始烧录。

归一化种子约束将暖偏色项从旧片 222/288、新片 199/250 改善到表中结果，但没有彻底解决。两个冻结版本及失败记录分别保存在 `tmp/hand_ccl_round2_20261017/` 和 `tmp/hand_ccl_round2_normalized_20261017/`，没有删除负面结果。

原始基准分类稳定段内切换次数均为 0；ROI 纵向变化 ≥64 像素的次数为旧片 2、新片 4。这只是变化量统计，不是带真值的框准确率，不能据此称追踪框完全稳定。

## 复现

在工程根目录执行，输出目录必须不存在：

```powershell
python -m unittest discover -s host/tests -p test_hand_ccl_prototype.py
python host/hand_ccl_regression.py --out tmp/hand_ccl_round2_reproduce
```

回归返回非零且打印 `SOFTWARE_STRESS_FAIL` 是本轮真实预期，不应改成成功退出以掩盖压力失败。准备数据使用 `host/hand_capture_replay.py VIDEO --out NEW_DIRECTORY`，不使用去框线代理替代原始片。

## 下一阶段

先修复颜色变化时的种子不足/背景混入，并降低暗场对绝对亮度门限的敏感性；继续保持基准和扰动两套结果分别展示。随后用独立新场景验证，补充框真值。

当前原型包含 OpenCV 连通域、凸包、距离变换和浮点几何，**不能直接据此宣称 FPGA 资源足够**。待分割稳定后，才用有上限的行程编码连通域、整数轮廓/掌部近似和复用 ERAM 实现 RTL，并重新做逐帧等价、资源及最终时序验证。距“全部功能保留且资源降低”的目标还有这一步，不会直接替换现有模块。
