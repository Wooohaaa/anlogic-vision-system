## 边界

此改动修正的是已复现的低占用门槛填孔问题。当前没有用户本次“8异常”的实拍输入，不能断言该故障只有这一原因。算法仍要求黑字白底、固定框与5×7模板较好对齐，不是任意字体/任意位置OCR。过细笔画（不足采样点12.5%）可能丢失；尺寸偏小、偏移、旋转、反光造成的失败仍需真实画面核验。尚无v66可烧录bit；需要新一轮整机综合布线后才能交付部署。
