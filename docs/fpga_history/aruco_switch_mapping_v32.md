# v32 拨码开关分配：合并 motion 与颜色/形状，SW2 控制 ArUco

| 开关/按键 | 功能 |
|---|---|
| SW1 (`I_detect_sw[0]`) | 同时显示 motion 与颜色/形状检测结果 |
| SW2 (`I_detect_sw[1]`) | 启停 MCU 上的 ArUco 识别与位姿估计 |
| SW3 (`I_detect_sw[2]`) | 预留 |
| SW4 (`I_detect_sw[3]`) | 数字识别 |
| KEY1 / KEY2 | 图像处理模式切换 |
| KEY3 | 自动白平衡开关 |
| KEY4 | 自动曝光与模拟增益开关（复位默认开启） |

板上拨码为低有效。SW1 在控制域消抖后，其使能同时送入 motion 与颜色/形状的显示门控。SW2 经过同一消抖模块后独立接入 MCU 总线域的两级同步器，MCU 从只读寄存器 `0x8000010c` 读取开关状态。复位时 SW2 对应使能为 0，识别默认关闭。

关闭 SW2 时，MCU 释放当前快照，停止启动新一帧识别，清除 ID、四角与位姿；打开 SW2 后从新帧重新识别。该开关不改变 PWM 安全授权，不会自动启动舵机。KEY4 每次消抖按下暂停/恢复曝光时间和模拟增益的逐帧自动调整，复位默认开启。暂停期间保持传感器当前目标值、清空亮暗确认计数；传感器当前正在执行的 I²C 更新会完成，不会中断半笔写入。重新开启后从新帧继续判断。

MCU 固件为 `deliverables/mcu_aruco_v32.elf`（已生成，SHA-256 `D71F9E6445BD5DDA454931D690CE615F9EF47D1B08E2EC9999A786B77CD575F0`）；完整硬件部署还需要使用更新后的 FPGA RTL 综合 bitstream。此次已同步 RTL 到 TD 工程，尚未生成新 bitstream，也没有上板验证。
