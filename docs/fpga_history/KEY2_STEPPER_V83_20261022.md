# v83：KEY2 开关步进云台追踪

## 操作

- 上电默认 OFF；上电时一直按住 KEY2 不会启动，必须先释放再按下。
- KEY2（A9）短按一次：以当前安全姿态为软件零点并开启红球追踪；再次短按：停止并释放驱动。不是机械回零，不会自动回中。
- 每次重新开启会重新确认当前参考位置。无编码器/限位，软件步数不能当作真实角度；启动前检查线缆及机械余量。垂直负载在关闭后可能失去保持力。
- 无目标时保持等待；重新连续收到三帧有效目标才允许运动。故障时不会靠长按或重试自动重启。
- KEY1 保留 0～6 全部图像模式的循环切换；KEY2 不再切换图像模式。KEY3 白平衡、KEY4 曝光功能不变。
- 电脑 `motor.ps1 on -ConfirmZero / off / status` 仍可使用，版本支持 v82/v83。

## 实现

FPGA：A9 → 原有 50MHz 两级同步 → 硬 MCU GPIO4。图像按键模块以 KEY2_TRACKING=1 关闭 KEY2 的反向模式选择；保留该模块的默认参数以兼容历史测试。

MCU：配置 GPIO4 输入，前台轮询，20ms 稳定消抖，释放后的一次按下只触发一次。不使用每步中断，不改追踪速度、ArUco、曝光、降噪或任何其他功能。

停止、看门狗和故障规则沿用 v82。开启前检查硬件空闲/无故障，置零和 ARM 每次最多执行一次；开启时清空旧目标稳定计数。
