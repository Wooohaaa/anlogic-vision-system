# v68 暗部彩色颗粒优化

## 输入与边界

用户两张HDMI截图显示增益后暗部有明显彩色颗粒。截图是已处理/编码后的画面，不是传感器RAW或ISP线性输入；本次没有拿截图逆推的伪RAW当真实噪声依据，没有宣称合成噪声指标等于板上改善比例。

工程基线为已烧录v67r1，保留其数字归一化识别、ArUco、MCU v55、全部其他功能和原时钟/引脚约束。资源目标仍Slice≤19518（用户92%）。

## 修改

`ua_photo_finish_96.v`新增静态参数 `SHADOW_COLOR_DENOISE`，兼容默认0；`isp_top_user.v`产品实例开启为1。

- 复用现有水平/因果垂直5点可分离有限FIR、5×5空间支撑和原行RAM，不增加帧缓存或递归反馈，不增加流水级。
- 暗区判断从所有RGB通道<64扩到<128（AWB之后8/9位线性码值，不是HDMI编码值）。这覆盖增益抬高后原先落入严格亮区门限的暗部。
- 暗部邻点同时满足三个RGB通道差在±31以内才参与滤波；原暗部±24，亮区仍±12。超过门槛的颜色/亮度边界继续回退为中心像素。不是无条件模糊，也不是单纯去饱和。
- 差值仍是有符号6位，权重和8的极值±248，9位加3舍入不溢出。故意不扩大到±32，避免既有窄差分实现溢出。
- 饱和度增强禁用范围由编码hi≤80扩到≤128，弱色差禁用门槛由16扩到24，避免再次放大暗部残留色差。没有将RGB混成灰度或新增黑位压缩。较亮的低饱和区域也可能少一些增强，不保证所有非暗区像素都完全不变。
- 真实低对比纹理在扩大门槛后会受到更强平滑，这是空间降噪的取舍；明确的强边缘、恒定颜色与高光由测试验证。

## 验证

`tools/test_shadow_color_v68.py`，`tmp/v68_color/result.json` 为 `SHADOW_COLOR_V68_RTL_PASS_NOT_BOARD`。

- 8/9位各100000组，±31窄差分核与全精度参考比较通过，含门限边界、舍入与溢出。
- 独立NumPy标量规则参考与RTL逐拍比较：32×32×3帧8位、1280×16×3帧9位、1280×720×3帧9位。开启产品运行时增益曲线和高光安全提升，包含帧首/行尾、第一/最后像素、随机气泡、脏行RAM后复位、帧强度锁存，全部匹配。
- 合成独立RGB噪声的暗灰区，滤波后色度差标准差从10.889降到2.904，约73.33%。这是特定合成噪声的线性域结果，不是实际相机改善承诺。
- 恒定中性/有色块的线性RGB值保持，强色细线和高光案例包含在逐像素回归中，高光区域与旧版输出逐字节一致。
- `tools/test_digit_v68.py`重新回归0–9、旧显式配置、用户数字视频关键帧和截断拒绝，全部通过；这不是降噪后真实相机到识别器的端到端证明。
