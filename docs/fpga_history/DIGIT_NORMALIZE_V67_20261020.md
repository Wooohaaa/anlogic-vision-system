# v67：实拍数字8错判修复

## 故障证据

用户视频：`C:/Users/Chieh yu/Videos/2026-10-20 18-03-01.mp4`，1280×720，60fps，819帧，13.65秒。联系图见 `tmp/v67_digit/contact.jpg`。不是上一轮理想网格测试。

实拍8相对绿色框不断移动、缩放，有时越出绿色框。即使完整进入绿色框，固定内网格仍不与笔画对应，能显示6或1。v66仅提高占用门槛，不能解决几何错位，因此不应以其理想栅格测试保证实拍识别。

## 算法修改

绿色框仍288×384，不再增大。内部增加24像素搜索保护区，按每四行采样、每4像素拍至少3个深色像素筛选笔画。采样行必须至少有8拍支持，排除零散噪声/细碎印刷点。累计数字包围盒，拒绝触及搜索边界、过小或过矮的候选。

利用上一帧包围盒归一化下一帧5×7网格，保留三帧确认。窄数字1保留两侧空白，不把窄竖线横向拉满。动态占用门槛采用37.5%单元采样量（位置/倾斜引起的笔画跨格在低门槛下仍会填孔）。该参数由实拍回放探索后确定，不对8设特殊优先规则，不关闭0–9中的任何数字。

网格尺寸以空闲周期重复减5/7求整步长，不使用并行除法器；占用门槛有小位宽面积乘法。ADAPTIVE_ROI=0保留显式CELL_MIN和旧固定采样行为，仅用于兼容测试。实际产品默认ADAPTIVE_ROI=1。
