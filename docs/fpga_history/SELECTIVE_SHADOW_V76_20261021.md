# v76：恢复真正暗像素的可见亮度

用户实测v75色彩改善，但暗处不如之前亮。保留v75测光封顶96及曝光反馈修复、基础曲线、温和逐通道提升和原5×5降噪。本轮不把全画面数字增益简单加回，也不改白平衡、MCU、引脚或约束。

## 算法与时序

新增默认关闭的`SELECTIVE_SHADOW_BOOST`，产品显式打开。后级以整个像素`max(R,G,B)`判断暗度，而不是分别判断三个通道。

令h为v75编码后最大通道，强档增加量为：h<64时floor(h/2)，64≤h<128时floor((127-h)/2)，h≥128时0；弱档再减半，关闭档为0。三个通道增加同一个量，最大31（在h=62..65附近），黑位0仍为0，整体最大通道曲线单调。此共同偏置保留绝对R-G/B-G差值，但不能宣称相对饱和度完全不变；暗色仍可能看起来较淡。中间调/高光和整像素较亮的彩色块不受该补偿影响。

三角包络由五位异或折叠实现，避免原型中的减法与乘三。复用饱和度处理末级的通道加法器，只增加两位强度对齐寄存器，没有新增像素处理拍、DSP或行/帧存储。强度在原帧首锁定并随encoded数据对齐，包含跨帧/气泡情况。
