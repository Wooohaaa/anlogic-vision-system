当前工程：`contest2_hdmi_video`；TD 项目：`prj/td_project/camera_to_dsi_display_hdmi.al`；器件 PH1P35MDG324，摄像头 SC500，1280×720。当前无网口，不使用舵机；红球云台使用双步进电机。

## 当前版本与控制

当前交付v94（倾斜数字卡定位、多尺寸模板、特征稳态过滤）：Slice19777/21216（93.22%）、ERAM108/108、DSP31/40；最终Routed SWNS +0.112ns、HWNS +0.020ns、STNS/HTNS为0。2026-10-24 20:33:53官方命令行完成联合Flash写入及校验，包含原MCU v83，未启动电机。40组位置/亮度、30组倾斜字、负例及真实5/7/9静态与36帧连续HDMI回放通过；独立核验703个冻结输入和镜像哈希。冷启动与板上真实识别效果待用户验证。保留原有功能和v91弱边缘效果，上限20000 Slice。详见 `docs/AUTO_DIGIT_REPAIR_V94_20261024.md`。v93r3、v92r1为历史交付；v93原轮、v93r1/r2均未烧录。v92因顶层作用域接线导致功能裁剪而撤回，从未烧录，禁止使用其bit；v90也是撤回试验，不是交付。

| 控制 | 功能 |
| --- | --- |
| KEY1 | 切换图像模式 |
| KEY2 | 开关步进云台追踪，启动前确认机械及供电安全 |
| KEY3 | 开关自动白平衡 |
| KEY4 | 开关自动曝光与亮度增益 |
| SW1 | 颜色/形状与运动检测；黄色运动框、MOV百分比或CAM:ON提示 |
| SW2 | ArUco 检测 |
| SW3 | 纯 FPGA 张掌/握拳手势检测 |
| SW4 | 任意位置单张数字卡识别，搜索时显示---，确认后显示绿色笔画框 |

数码管固定显示整体增益 index（00～31）和使能0/1，不轮换白平衡系数。手势 H:O=张掌、H:F=握拳、H:-=无可靠分类；T:7表示错误帧，T:3表示张掌分支支持，T:0表示拳头/无候选，不是通用手指计数。

数字识别面向单张完整的浅色中性卡片及深色印刷数字0～9，可覆盖已回归的适度倾斜；不要求放在中央固定框。测试卡在 `deliverables/digit_cards.html`，每次展示一张，保持片刻；SW4开启未确认显示---，关闭留空，撤卡后清除。确认结果在定位有效时最多容忍五帧短暂拒识，不代表任意字体、手写、多数字或大透视自然场景OCR。颜色/形状候选改用ERAM，像素路径和吞吐量不变，检测元数据额外延后3拍。

运动检测采用相邻帧差与32×32网格过滤，MOV表示有效运动网格的整数百分比，不是物体数量/速度；小于1%可能显示000%但仍有框。停住后框保留两帧，云台有步进脉冲时显示CAM:ON并隐藏运动框，停止后三个安静帧再恢复。多处运动可能合为一个框，灯光突变及手动移动相机仍可能误报。真实识别质量不由RTL测试自动保证。

HDMI 四周2像素黑边只用于掩盖顶部线条，不缩放、搬移图像，不修复传感器侧异常。ArUco标记黑边120mm；尚未完成实机相机标定，轴不能称为精密测量。手势仍有困难场景误识别，离线回归不等于板上准确率保证。

## 源码与资料

- `rtl/user/`：维护RTL；`rtl/official/`：官方IP及维护过的接口代码。
- `prj/user_source/`：由setup同步的TD副本，不直接修改。
- `../mcu_tracking/`：MCU/ArUco/步进控制与接线资料。
- `host/tests/`、`tools/`：测试与版本化构建/部署工具。
- `deliverables/`：交付固件及回退版本，清理时保留。
- `docs/`：设计、测试、部署和清理记录；根目录历史文档也保留。
- `tmp/`：既有可再生成缓存，也有启动镜像、MCU哈希和回归输入，**不能整目录删除**。

## 常用命令

在工程根目录执行：

```powershell
python tools/build.py verify
python tools/build.py setup
python tools/audit_project_v90.py
./tools/clean_generated.ps1
./tools/clean_generated.ps1 -Apply
```

setup/verify默认选择当前binary手势；历史方案仅显式使用 `--native-hand` / `--legacy-hand`，不能把历史构建脚本当作当前部署入口。setup只同步并检查，不综合、不烧录。完整构建和烧录使用对应新版本脚本，必须通过实际Routed时序和镜像核验；成功回执存在时不重复下载同一版本。

清理工具默认只预览，Apply才删除；记录在 `docs/cleanup_*.json`。仅删除验证过的项目内可再生成文件，保留文档、视频、源码、ROM/IP、固件、回执和当前/回退关键输入；不会访问USB/串口或开启电机。清除旧仿真库后，相关测试会重新编译；历史版本断点数据库删除后不能从那些断点恢复。

旧版入口说明完整保留在 `docs/README_HISTORY_BEFORE_AUDIT_20261023.md`，其按键、数码管和部署说明已过期，勿照做。
