# 随动摄像头：先确定云台轴向

用户已确认两只电机均能在 v77 双轴有限扫描中实际运动；摄像头现在安装在云台上并随其转动，左右/上下轴及正方向未知。

## 控制方式变化

原 v69 是固定摄像头：图像坐标经过仿射映射得到绝对步数。随动摄像头应使用图像中心误差闭环；方向未知时，错误的反馈符号会让目标越追越远。因此 v78 暂时锁住旧 `g` 入口并停止电机，不伪装成已经完成随动追踪。

本轮只增加单轴识别实验，不改 FPGA RTL、引脚或视频算法。两轴硬件仍用已布线 v77，Slice 19465/21216（91.75%），ERAM 97，DSP 32，SWNS +0.009ns，HWNS +0.020ns。

## MCU v78 命令

USB UART0 COM15，115200/8N1；不改变 DTR/RTS，不复位板卡。上电默认 OFF。

| 命令 | 行为 |
|---|---|
| `?` | 读取 STEPPER v78 状态 |
| `s` | 停止并撤销软件零位 |
| `z` | 仅在 OFF 时将当前已确认安全的位置设为临时零位；不是物理回零 |
| `x` | 仅轴0：+80 → -80 → 0 步，最高80pps，mode=3 |
| `y` | 仅轴1：+80 → -80 → 0 步，最高80pps，mode=4 |
| `n` | 保留原双轴有限扫描；轴向识别时不要使用 |
| `g` | 暂时拒绝旧固定摄像头追踪，并保持/转为 OFF |

每次试验必须先确认 OFF、重新建立安全零位；15秒期限、100ms MCU服务停顿和250ms FPGA看门狗继续有效。一次只发一个测试命令，完成后自动关闭；停止时俯仰负载可能失去保持力，须托稳。无编码器，`pos` 只代表已发脉冲，不代表实际机械位置。

先观察 x：记录是左右还是上下、第一次偏向哪边；再观察 y。方向应按摄像头/云台实际运动描述，必要时用固定场景在画面中的相反位移核对。未确认方向前不启动持续闭环。

## 板上单轴试验记录

2026-10-22，重新上电后收到 STEPPER v78、available=1、mode=0，确认新 MCU 已运行。轴0 x 实验完成，抽样计数 [79,0]→[14,0]→[-61,0]→[-32,0]→[0,0]，随后确认 OFF；用户观察“上下，先上再下再上”，因此轴0=俯仰、正向朝上、负向朝下。

随后轴1 y 实验完成，抽样计数 [0,79]→[0,14]→[0,-61]→[0,-33]→[0,0]，全程轴0计数为零，最终 OFF，步进故障位未置位，MCU最大服务间隔34ms。轴1实际物理方向等待用户观察确认，不能仅依据计数推断。两次实验均未开启持续追踪。
