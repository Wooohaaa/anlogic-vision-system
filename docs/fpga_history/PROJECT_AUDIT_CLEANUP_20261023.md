## 发现但未冒险消除的问题

### TD前期同步器约束空对象告警

原SDC的SW2接收端第一同步级在展开阶段仍是vector，而最终网表是scalar，造成前期 `set_false_path -to ...detect_sync_reg[0]` 空对象critical warning；最终v89数据库中精确命中1个stage0单元。不能因此扩大为整个100MHz/50MHz时钟对false path，否则会掩盖正常路径。

本轮尝试阶段感知写法，但TD缓存/重放SDC对象后仍在前期告警，被新的严格检查拦截。v90只完成综合/布局，没有布线、封装或烧录；试验已撤回，原SDC逐字节恢复至v89。失败日志和receipt保留，不把它们当交付。本轮不声称修复了这条告警。

`tools/audit_v90_timing.tcl` 是只读数据库核验工具：载入v89 Routed DB，重新读原SDC，核对stage0精确命中和最终时序，不导出数据库、不生成bit、不访问板卡。最终复核日志为 `tmp/v90_final_baseline_timing.log`。
