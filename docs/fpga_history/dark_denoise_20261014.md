# 暗光降噪 v21（2026-10-14）

用户已确认 v20 HDMI 画面正常；本轮处理暗光噪点，不改曝光策略、白平衡、黑位、亮度曲线、颜色饱和度或 MCU 控制。

## 算法变化

修改 `rtl/user/ua_photo_finish_96.v`。降噪位于 AWB 之后、显示编码之前。维持横向 [1,2,1] 相近颜色滤波及原有一行缓存：

- 中心像素所有通道均小于 64 时，相似邻域阈值由每通道差值 18 改为 24；亮像素仍为 12。
- 垂直相似像素均为暗像素时，由 1/2 当前 + 1/2 前行改为 1/4 当前 + 3/4 已滤波前行，带整型四舍五入。
- 不相似邻域、首行及无历史时仍输出中心值；强轮廓不会被跨边平均。低于范围门限的微弱纹理可能被平滑，不能宣称所有细节完全保留。
- 不增加帧缓存，不跨帧平均，不新增像素流水级。宽度小于 16 的测试配置仍使用原来的两行 FIR 历史方式，避免 RAM 读写碰撞。
- 新增 `DARK_DENOISE=1` 参数，可设 0 恢复原来的降噪数值策略；色调 LUT 保持原值。

门限是模块输入的线性 RGB 码值，不是 HDMI 编码后的 8 位亮度，也不是传感器 RAW10 黑位。9 位输入保留 AWB 余量，不对本轮门限作另一次曝光增益。
