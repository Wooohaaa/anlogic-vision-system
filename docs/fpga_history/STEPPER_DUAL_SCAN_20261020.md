# 双路步进扫描：接线预案与实现状态

## 当前状态

这是 DCC-100v3 双电机扩展的**原型与接线预案**，不是可烧录的整机完成报告。
曝光修复 v59 正在独立布线；该构建未包含步进模块。为保持其冻结输入不变，步进原型暂放 `addons/stepper/`。
尚未接入 MCU 总线、顶层管脚或部署脚本，尚未上电测试电机。

## 供电：先处理，再测试

用户目前用开发板引出的 5V 经升压到 15V 给驱动供电。由于开发板接口、电源和升压模块可供电流均未核实，**不要继续使用这条供电链测试两只电机**。请先断开，改用符合电机和驱动要求的独立电源。

驱动说明书给出的驱动板输入范围是 11–26V，逻辑是 3.3V。15V 落在驱动输入范围内，但这不等于电机电流/温升已安全。还需确认两只电机型号、驱动限流、连续工作电流及升压效率。
升压并不增加可用功率：例如输出 15V/1A，在效率 85% 时输入 5V 约需 3.53A；这是说明功率关系的例子，**不是对实际电机耗流的测量**。

用户补充升压模块为 MT3608、电机型号写作 `42BL382.0-23A`。尚无可核实的原厂电机额定电流，不能把型号中的数字直接当额定值。MT3608 芯片或模块的标称不能直接当作当前 5V→15V、双电机条件下的连续输出能力；仍需电机铭牌、模块实物、电源规格与开发板5V允许电流。用户尚未确认已断开这条电机供电链。

- 驱动电源负极和开发板 GND 共地；电机回流直接回独立电源，不串过板卡细信号地线。
- 11–26V 电源只进驱动板标注的电源端，不接 FPGA GPIO、3.3V 或 5V。
- 电机断电后按 A+/A-/B+/B- 丝印接线，不猜线色，不带电插拔绕组。
- 电流设定方法和电机额定电流确认前，不提供未知的电位器位置或限流数值。
- 首次测试卸载、离开机械限位，准备能直接断开电机电源的开关。

## 拟定接线（整机集成前，暂勿按此接通电源）

原理图 `使用资料/02_HX1P35A开发板资料/HX1P35B_FT.pdf` 第2页 BANK32、第7页扩展口，与现有舵机使用的 C18/D15 排针对应。
不同版本手册的 J1/J2 命名不一致，请以**现有舵机所在排针、GPIOB 网络名和 FPGA 球号**辨认，不凭“左边第几个”判断。现有 C18/D15 舵机保持原样。

| 驱动信号 | 拟用 FPGA 球号 | 对应原理图排针 | 说明 |
|---|---|---|---|
| 通道1 PWM/STEP | E12 / GPIOB2 | J2.3 | 3.3V 脉冲 |
| 通道1 DIR | E16 / GPIOB3 | J2.4 | 方向 |
| 通道1 SLP 和 RST | E17 / GPIOB4 | J2.5 | 二者同接该使能线，低电平关闭 |
| 通道2 PWM/STEP | F13 / GPIOB5 | J2.6 | 3.3V 脉冲 |
| 通道2 DIR | F14 / GPIOB6 | J2.7 | 方向 |
| 通道2 SLP 和 RST | F18 / GPIOB7 | J2.8 | 二者同接该使能线，低电平关闭 |
| 两路 GND | 板卡 GND | J2.12 | 与独立驱动电源负极共地 |
| 两路 DCY | 不接 FPGA | 驱动 DCY 悬空 | 按模块说明书的自动衰减用法 |

两路控制端物理排列可能镜像，逐一核对驱动板丝印。建议 STEP 与 SLP/RST 各加 10kΩ 对地电阻，降低 FPGA 配置期间浮空误动作风险。最终 ADC 管脚冲突检查、实板排针方向和接线照片核验完成后，才把这张预案升级为可用接线表。

## 分工与行为约定

- FPGA：50MHz 单时钟计时，发 STEP、保持 DIR，精确计步、换向停顿、唤醒等待及 250ms 心跳超时停机。不产生新时钟，不走视频像素时钟。
- MCU：非阻塞服务启动/停止/状态和心跳；没有每步中断，不加入手势计算，保留 ArUco 与既有舵机控制。
- 启动后默认关闭。明确启动一次只执行有限扫描，不上电自动转，也不永久循环。
- 初始相对位置是 0，不是物理归零。扫描轨迹为 `0 → +span → -span → 0`；多轮在两端往返，最后回到命令起点。没有编码器或限位，堵转/断电后的实际位置未知。
- 默认通道1 span=160步、100步/秒；通道2 span=80步、50步/秒；一次扫描。配套电机若确为说明书的 0.05625°/脉冲，则半幅分别约9°与4.5°。其他电机/减速比不套用这个角度。
- STEP 高5µs，换向前停250ms，DIR 更改后至少一个低周期，驱动唤醒等50ms。这是保守原型配置，尚未取得芯片时序与实板运动验证。
- 配置限幅：半幅1–640步、周期5000–50000µs、1–4轮。运行中不改参数；双轴同时有效才接受启动。急停立即 STEP=0、SLP/RST=0；截断步进脉冲后不得宣称实际位置仍准确。
- 两轴独立使能和状态；一轴完成就关闭，不保持堵转电流。MCU停止心跳后，两轴最迟约250ms关闭。这是逻辑保护，不替代电源保险、硬限位和物理急停。
