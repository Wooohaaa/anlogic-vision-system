# v69：红球双步进旋转云台

## 当前实现及边界

替换产品顶层的两路舵机输出，接入两路 STEP/DIR/AWAKE。保留 v68 视频、曝光/白平衡、降噪、所有检测及 ArUco。历史舵机 RTL 的默认参数分支仅供旧测试使用，产品顶层明确 ENABLE_STEPPER=1，不实例化舵机脉冲发生器。不能给 v69 加载旧 v55 MCU 控制程序。

本版本实现了步数位置控制、有限扫描、固定摄像头的仿射标定入口与目标跟踪，**没有实测机械标定**。默认未武装、未标定；看到红球不自动运动。脉冲计数不是编码器位置，没有新增实际回零/硬限位传感器。

用户在本轮确认驱动/电机尚未接线，型号仍为 `42bl382.0-23a`；部署不执行动作。接线与限流验收仍待后续实物核对。

```
原 FPGA 红圆检测 → UART1 320×180 坐标
 → MCU 最新目标/绝对坐标映射/10ms 速度规划
 → 原 AHB/APB 总线 → 双轴硬件 STEP/DIR → DCC-100v3
```

摄像头仍固定。移动云台不会改变目标像素位置，因此不能对中心误差一直积分。标定映射是 `steps=(a*x+b*y+c)/4096`，两轴各一行，可表示方向、轴交换和线性耦合。仅适用于已标定的工作平面；任意深度与非线性机构需要后续分段/几何标定。

## 实现参数

- FPGA：50MHz 总线时钟，共享 1µs 使能，不生成低速逻辑时钟；STEP 高 5µs，DIR 换向前后低电平保护，唤醒等待 50ms。
- 两轴原子提交目标/速度，绝对软范围 ±640 步。硬件接受速度 ±1000pps；当前 MCU 首次调试限速 200pps、每 10ms 最多改变 10pps，末端低速逼近，绝不越过已提交目标。NCO 在脉冲/方向保护阶段暂停，实际脉冲频率略低于设定上限。
- 正常丢目标超过 150ms，MCU 减速到零并保持驱动使能；主循环超过 100ms 未服务则请求硬关闭。硬件 250ms 无有效更新自动关闭并清除原点有效状态。关闭允许完成正在输出的脉冲，随后保持短暂尾部时间才释放 AWAKE。
- `s`、看门狗、重新上电后均须重新确认物理零位，不自动恢复运动。未接机械自锁/制动的俯仰轴，断使能可能下坠；首次测试须卸载或可靠托住负载。
- 软件零位不等于自动回零。丢步、机械阻挡后计数不再代表实际角度；必须停机重新建立参考。

## 接线（断电操作）

2026-10-22 一脚一线修订见 `STEPPER_DEDICATED_PINS_20261022.md`：新增两路独立 RST，须烧录新版 FPGA 固件后生效，旧 v76r1 不支持。SLP/RST 逻辑同步但物理引脚独立，不能短接两个 FPGA 输出。

依据本地 `HX1P35B_FT.pdf` 第2页 BANK32=VCC_3V3、第7页 J2 IDC40 GPIOB 排针；引脚表已与当前 ADC 冲突检查。**排针型号/版本或丝印不同，先对照板卡，不凭照片方向数针。**

| 信号 | FPGA 球脚 | 排针 | DCC-100v3 |
|---|---|---|---|
| 电机0 STEP | E12 | J2.3 / GPIOB2 | 第一路 PWM |
| 电机0 DIR | E16 | J2.4 / GPIOB3 | 第一路 DIR |
| 电机0 SLP | E17 | J2.5 / GPIOB4 | 第一路 SLP |
| 电机1 STEP | F13 | J2.6 / GPIOB5 | 第二路 PWM |
| 电机1 DIR | F14 | J2.7 / GPIOB6 | 第二路 DIR |
| 电机1 SLP | F18 | J2.8 / GPIOB7 | 第二路 SLP |
| 电机0 RST | G17 | J2.9 / GPIOB8 | 第一路 RST |
| 电机1 RST | H17 | J2.10 / GPIOB9 | 第二路 RST |
| 信号地 | — | J2.12 / GND | 驱动 GND，与独立电源负极共地 |

DCY 可不接，按驱动手册使用自动衰减。驱动控制侧为 3.3V；**12V 只接驱动绿色电源端，不能接任何 FPGA 信号脚**。电机大电流回流直接回独立电源，不经开发板排针。不要再从开发板5V升压供电。

建议驱动 SLP/RST 配置期有外部下拉，避免 FPGA 未配置时输入悬空；先核对模块是否已有下拉。独立12V/2A仅确认电压范围合适，未证明双电机负载余量足够。`42BL382.0-23A` 的相电流/接线尚未核验，必须结合铭牌、驱动限流、压降和温升确认。禁止带电拔插电机绕组。

## 人工调试命令（USB UART0；不由部署脚本发送）

波特率沿用当前 MCU SDK UART0 配置。先确认 `?` 输出 `STEPPER v69`、available=1、mode=0，ArUco 仍有状态。产品下载本身不会发送以下动作命令。

1. 不接电机或先卸载/托住机构，核验脉冲和接线，之后人工选择驱动上电。
2. `s`：关闭，清除原点授权；手动把云台放在安全中央参考位置。
3. `z`：确认此处为零。仅停止且 AWAKE 已释放才成功；不是物理寻零动作。
4. `n`：有限扫描 `(+80,+40)→(-80,-40)→(+80,+40)→(-80,-40)→(0,0)`，15秒硬期限，结束关闭。先观察两个电机方向、传动与供电，再放大范围。0.05625°/脉冲仅在手册对应电机/细分配置下成立。
5. 获取实际标定点，拟合两行 Q12 仿射系数。在 OFF 状态发送 `M a b c d e f\n`（六个十进制整数），程序验证四个画面角点均在 ±640 步内才接受。通过 `?` 确认 calibrated=1。
6. 重新安全置零，`z` 后 `g` 请求跟踪；未标定时拒绝。红球丢失减速保持，`s` 关闭。**没有装配数据时不要凭空填示例系数上电跟踪。**

本轮不自动运行扫描、跟踪或舵机。不宣称机械跟踪精度或丢步保护已经验证。
