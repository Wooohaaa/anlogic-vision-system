# 系统设计说明

系统采用四像素并行视频流水线，输入分辨率为1280×720。摄像头输入经ISP、自动白平衡、曝光与亮度控制和降噪后，进入图像模式与检测旁路；DDR完成帧缓存，HDMI叠加Logo、模式、链路延迟、IN/OUT帧率和识别结果。

数字卡定位聚合浅色背景内的深色游程，并按实际字形宽度提取五列七行特征。各列分配整数余数，按自身宽度计算占用率。同步ROM保存合成尺寸与倾角模板，串行汉明距离匹配与闭环字形质量检查配合时域确认与分类一致性检查，发布数字和定位框。

颜色形状采用红绿蓝掩码、有限候选分离、投影框和填充率分析，发布圆形、方形、长条形与三角形结果。运动检测通过帧差和网格统计绘制区域框；手势模块提供张掌与握拳交互。

FPGA对ArUco输入进行取样，板内MCU完成候选提取与字典解码，HDMI绘制标记ID、四边形和方向轴预览。MCU根据红色目标坐标计算双轴控制请求，FPGA执行步进脉冲时序。
