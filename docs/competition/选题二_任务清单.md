## 0. 总览

### 0.1 系统架构（目标形态）

```
SC500CS (5MP, MIPI 2-lane, RAW10, 2592x1944@30fps)
  └─> MIPI CSI RX (D-PHY + CSI-2 解包)
        └─> RAW10→RGB 转换 (增益/白平衡钳位)
              └─> 片上 DDR 帧缓存 (三缓存)
                    └─> 读出 + 双线性缩放 (→720p / 1080p)
                          └─> 算法域 (显示分辨率)
                          │    ├─ 灰度化
                          │    ├─ Sobel 3x3 边缘检测
                          │    ├─ 二值化 (固定/OTSU)
                          │    ├─ HSV 色块检测 + 跟踪
                          │    └─ 帧差运动检测 (320x180 缩放域)
                          └─> OSD 叠加 (安路Logo + 文字 + 检测框 + 帧号)
                                └─> HDMI TX (720p60 / 1080p60)
```

## 2. P1 — 自有链路搭建（缩放 + 帧控 + OSD 骨架）

### 2.1 模块划分与接口定义

约定接口风格：`valid`/`ready` 握手，视频流统一为 `{vsync, hsync, de, [23:0] pixel}`。

```
top
├── clk_rst_gen        PLL: 74.25M(显示) / MIPI RX 恢复时钟 / DDR 时钟 / 50M(板载输入)
├── mipi_csi_rx        (lab_ex_1 继承) → raw10_stream: {valid, data[9:0]}
├── raw_to_rgb         RAW10→RGB888, 增益钳位
├── write_ctrl         DDR 写控, 三缓存管理: {wr_frame_id[1:0]}
├── ddr_ctrl           安路 DDR IP (照 lab_ex_1 用法)
├── read_scaler        DDR 读 + 双线性缩放 → disp_stream
├── algo_pipeline      P2 算法插入点（P1 先直通 bypass）
├── osd_engine         Logo + 字库 + 检测框叠加
├── hdmi_tx            (lab_ex_1 继承) 720p60 时序
└── key_ctrl           按键消抖 → 算法切换 / OSD 翻页
```

关键接口签名（Verilog 头级别）：

```verilog
// 读出缩放输出（算法域输入）
output              disp_vs, disp_hs, disp_de,
output [23:0]       disp_rgb,        // RGB888 @74.25MHz 像素时钟
// OSD 输入侧（由 algo_pipeline 回传）
input  [10:0]       osd_x, osd_y,    // 当前像素坐标（可由 scaler 同步生成）
```

## 3. P2 — 基础算法（对照基础要求 4 条）

### 3.1 算法流水线设计（全部工作在显示分辨率域）

`algo_pipeline` 内部为一条可旁路的多级流水的 3×3 卷积骨架，算法即"系数 + 后处理"配置：

```
disp_rgb → RGB2GRAY → [3x3 window] → {Sobel | 高斯 | 直通} → 后处理(二值化/钳位) → 算法选择器 mux → osd_engine
                                   ↘ (并行)HSV色块检测 / 帧差路径 ↙
```

每级 3×3 窗口缓存：2 行 × 1280 × 8bit = 20 Kbit（720p 域）。
