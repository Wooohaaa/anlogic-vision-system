# 操作与部署

KEY1切换图像模式，KEY2开关双步进跟踪，KEY3开关白平衡，KEY4开关自动曝光与亮度增益。SW1控制颜色形状与运动，SW2控制ArUco，SW3控制手势，SW4控制数字识别。

板上采用联合Flash启动，电机默认关闭。电机使用独立12 V供电，并与开发板共信号地；控制接口为3.3 V。详细排针定义见技术文档。

工程构建与烧录使用仓库根目录tools/repository.py，安装路径通过config.local.json或环境变量配置。firmware目录保存FPGA配置、MCU应用和联合镜像，PACKAGE_MANIFEST.json提供SHA256校验。
